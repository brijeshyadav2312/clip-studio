# Caption fonts

These fonts are bundled so the browser preview and the libass/ffmpeg burn use the
same typeface. They are all licensed under the SIL Open Font License 1.1.

| File | Family | Source |
|---|---|---|
| `Anton-Regular.ttf` | Anton | https://github.com/google/fonts/tree/main/ofl/anton |
| `ArchivoBlack-Regular.ttf` | Archivo Black | https://github.com/google/fonts/tree/main/ofl/archivoblack |
| `BebasNeue-Regular.ttf` | Bebas Neue | https://github.com/google/fonts/tree/main/ofl/bebasneue |
| `Poppins-Bold.ttf`, `Poppins-ExtraBold.ttf` | Poppins | https://github.com/google/fonts/tree/main/ofl/poppins |
| `Montserrat-Variable.ttf` | Montserrat | https://github.com/google/fonts/tree/main/ofl/montserrat |
| `Rubik-Variable.ttf` | Rubik | https://github.com/google/fonts/tree/main/ofl/rubik |
| `Oswald-Variable.ttf` | Oswald | https://github.com/google/fonts/tree/main/ofl/oswald |

The OFL permits bundling and redistribution with software. Keep this notice with
the fonts if you redistribute the project.
